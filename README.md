# 伊莉莎白設計工作室｜網站原型

繁體中文靜態網站，包含首頁、設計服務與作品集。

## GitHub Pages

1. 建立公開儲存庫，例如 `elizabeth-design-studio`。
2. 將這個資料夾內的 `index.html`、`services.html`、`portfolio.html` 上傳到預設分支根目錄。
3. Repository Settings → Pages → Build and deployment → Deploy from a branch → main / (root)。
